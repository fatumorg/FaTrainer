Insert

Every FaTrainerworks the same way.

One launcher

It finds the game in your Steam libraries, puts a single DLL in its folder and starts the game with the trainer on. Start the game from Steam and you play it without the trainer.

A menu over the game

Press Insert or F8. While it is open the game ignores your mouse and keyboard.

Windows and Linux

On Linux it runs through Steam's Proton with one launch option.

Only a version check

When you start the game from the launcher, the Fatum Version asks GitHub which version is newest, fetches newer builds of your version and stays off after a newer version until you update; the Nexus Version on Nexus Mods skips even that. Nothing else leaves your PC; settings and a log stay next to the game.
