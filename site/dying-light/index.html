One launcher,one Play button.

FaTrainer is a small launcher. Press Play: it downloads the newest trainer from the GitHub release when yours is older, checks it against the release checksum, puts xinput1_3.dll next to the game and starts Dying Light through Steam with the trainer on. Start the game from Steam instead and you play the normal game; the file stays, but the trainer does nothing. Pick an older version from the list, or tick Beta builds for the version being worked on. FaTrainer also reads a small version file from GitHub and updates itself.

Windows

  1. Download FaTrainer.exe and open it. Add shortcut puts FaTrainer on your desktop and in the Start menu.

  2. It finds Dying Light in your Steam libraries. If it does not, choose the folder with DyingLightGame.exe.

  3. Press Play and press Insert or F8 in game.

Linux with Proton

  1. In Steam, open Dying Light's Properties, then Compatibility, and force a Proton version. The trainer works in the Windows version of the game, not the native Linux one.

  2. Download FaTrainer for Linux, unpack it and run FaTrainer. It needs curl or wget, which almost every distribution has. On NixOS, start it with steam-run ./FaTrainer. Add shortcut puts it in your app menu.

  3. It finds the game in your Steam libraries, Flatpak and Snap included.

  4. In the game's Properties, paste this into Launch options:

    WINEDLLOVERRIDES="xinput1_3=n,b" %command%

  5. Press Play in FaTrainer and press Insert or F8 in game.

Before you play

Back up your saves

Item, level and rank changes are saved like any other progress. Keep a copy of your save folder before you try something big.

Other players

In co-op and Be The Zombie the trainer changes your game, and through it theirs. Switch things off when you play with people who did not agree to it.

Techland's rules

Modifying the game online may break Dying Light's terms of use. What Techland does about an account is between you and Techland.

Updates

When you start the game with Play, the Fatum Version of the trainer downloads a small version file from GitHub. Play already installs the newest version first; a newer build of your version, like 2.3 b2 after 2.3 b1, downloads itself, is checked against its checksum and starts the next time you open the game. If a newer version is out, the trainer stays off until you press Play in FaTrainer again, unless you turned on Use older versions in Settings; the game itself keeps working. Started from Steam, the trainer stays off and connects to nothing. Nothing else is sent, and without internet the trainer works as usual. The Nexus Version on Nexus Mods has no update check and never connects to the internet, and neither does the Visuals Version, which FaTrainer installs when you tick Visuals only.

If something breaks

The trainer writes fatrainer.log next to the game. Attach it when you report a problem.
