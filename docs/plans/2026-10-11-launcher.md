# FaTrainer Launcher Implementation Plan

**Goal:** The FaTrainer Installer becomes the FaTrainer launcher; the trainer runs only when the game was started with its Play button.

**Architecture:** The proxy `xinput1_3.dll` stays in the game folder, but its main thread starts the trainer only when it finds a fresh `fatrainer.launch` file (Unix time) next to itself, which it deletes. The launcher's Play job installs the channel's newest DLL when needed, writes the file, starts the game through Steam and waits until the DLL consumed it.

**Tech Stack:** C++17, Dear ImGui, mingw (DLL, Windows launcher), zig cc (Linux launcher), Wine for the self test.

**Spec:** `docs/specs/2026-10-11-launcher-design.md`

## Global Constraints

- No comments in any file. No hint of AI assistance anywhere.
- Product name of the trainer stays `FaTrainer | Dying Light`; the launcher app is named `FaTrainer`. All UI text English.
- Trainer version `2.3 b4` (name stays `Keybind Update`), `INSTALLER_VERSION` `2.0`.
- Arm window: written at most 180 s before now and at most 30 s after now.
- Keep the release tag `installer` and the files `installer-windows.txt` / `installer-linux.txt`.
- Memory and game rules from `CLAUDE.md` are untouched; the trainer code after the arm check is unchanged.
- Build: `./build.sh`, `./build_installer.sh`; self test command from `CLAUDE.md`.

## Spec amendments (found while planning)

- The `FaTrainer-launch:1` tag is dropped. The launcher knows arming from the version: `FIRST_ARMED_VERSION` `2.3 b4`. An installed trainer older than that runs on every start anyway, so Play starts the game and finishes right away instead of waiting for the file. This lets launcher 2.0 ship before 2.3 final: until then the launcher installs 2.2 for non-beta users, which behaves like today.
- The launcher installs whenever the installed version differs from the channel's version (covers older, newer after leaving beta, and `1.x`).

## Review Focus

- Game already running when Play is pressed: Steam only focuses it, the file is never consumed; after 180 s the launcher removes it and says so. Covered by the timeout path in Task 3.
- Launcher closed during the wait: the file stays, but the DLL treats it as stale after 180 s and deletes it on the next start. Covered by `launch_armed` tests in Task 1.
- Garbage or empty `fatrainer.launch`: parses to 0, which is stale. Test in Task 1.
- Offline with an armed trainer installed: Play skips the download and still arms. Task 3 button logic.
- Proton without the launch option: the DLL never loads, the timeout message tells Linux users to add it. Task 3.

```cpp
inline const char* LAUNCH_FILE = "fatrainer.launch";
inline const char* FIRST_ARMED_VERSION = "2.3 b4";
const long long LAUNCH_MAX_AGE = 180, LAUNCH_MAX_AHEAD = 30;

inline bool launch_armed(long long written, long long now) {
    return written > 0 && written <= now + LAUNCH_MAX_AHEAD && now - written <= LAUNCH_MAX_AGE;
}
```

In `src/dllmain.cpp` (needs `<ctime>`), before `DllMain`:

```cpp
static bool launched_from_launcher() {
    char armed[8] = "";
    if (GetEnvironmentVariableA("FATRAINER_ARMED", armed, sizeof armed) && !strcmp(armed, "1")) return true;
    std::wstring path = own_path();
    path = path.substr(0, path.find_last_of(L"\\/") + 1) + std::wstring(LAUNCH_FILE, LAUNCH_FILE + strlen(LAUNCH_FILE));
    FILE* f = _wfopen(path.c_str(), L"rb");
    if (!f) return false;
    long long written = 0;
    if (fscanf(f, "%lld", &written) != 1) written = 0;
    fclose(f);
    DeleteFileW(path.c_str());
    return launch_armed(written, (long long)time(nullptr));
}
```

```cpp
inline void start_play() {
    fs::path game;
    bool on_beta, install;
    ReleaseInfo latest;
    std::string installed;
    {
        std::lock_guard<std::mutex> l(M.mx);
        if (M.job == Job::working) return;
        game = M.game, latest = M.latest, on_beta = M.on_beta, installed = M.installed;
        install = needs_install(M.installed, M.latest, M.fetch == Fetch::ready);
        M.job = Job::working, M.step = install ? "Downloading" : "Starting", M.progress = 0, M.message.clear();
    }
    std::thread([game, latest, on_beta, install, installed]() mutable {
        if (install) {
            /* existing download, checksum, backup, write code from start_install, base = on_beta ? BETA_DOWNLOADS : RELEASE_DOWNLOADS */
            installed = latest.version;
            std::lock_guard<std::mutex> l(M.mx);
            if (M.game == game) M.installed = installed;
        }
        std::error_code ec;
        fs::path arm = game / LAUNCH_FILE;
        bool armed = !newer_version(FIRST_ARMED_VERSION, installed);
        if (armed) std::ofstream(arm, std::ios::trunc) << (long long)time(nullptr);
        {
            std::lock_guard<std::mutex> l(M.mx);
            M.step = "Starting Dying Light", M.progress = 0.98f;
        }
        platform::launch_game();
        std::string running = "Dying Light is starting with FaTrainer " + installed + ". Press Insert or F8 in game. Starting the game from Steam plays it without the trainer.";
        if (!armed) return finish(Job::done, running);
        for (long long waited = 0; waited < LAUNCH_MAX_AGE * 1000; waited += 500) {
            std::this_thread::sleep_for(std::chrono::milliseconds(500));
            if (!fs::exists(arm, ec)) return finish(Job::done, running);
            std::lock_guard<std::mutex> l(M.mx);
            M.step = "Waiting for Dying Light", M.progress = 0.98f;
        }
        fs::remove(arm, ec);
        finish(Job::failed, platform::LINUX ? "Dying Light did not load FaTrainer within 3 minutes. Add the Steam launch option below once, then press Play again."
                                            : "Dying Light did not load FaTrainer within 3 minutes. If the game was already running, close it and press Play again.");
    }).detach();
}
```

```cpp
inline std::vector<fs::path> shortcut_files() {
    std::vector<fs::path> out;
    for (REFKNOWNFOLDERID id : {FOLDERID_Desktop, FOLDERID_Programs}) {
        PWSTR dir = nullptr;
        if (SUCCEEDED(SHGetKnownFolderPath(id, 0, nullptr, &dir))) out.push_back(fs::path(dir) / L"FaTrainer.lnk");
        CoTaskMemFree(dir);
    }
    return out;
}
inline fs::path shortcut_file() {
    auto files = shortcut_files();
    return files.empty() ? fs::path() : files[0];
}

inline bool add_shortcut(const std::string&, std::string& error) {
    CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED);
    fs::path exe = self_path();
    for (const fs::path& file : shortcut_files()) {
        IShellLinkW* link = nullptr;
        IPersistFile* persist = nullptr;
        bool ok = SUCCEEDED(CoCreateInstance(CLSID_ShellLink, nullptr, CLSCTX_INPROC_SERVER, IID_PPV_ARGS(&link)));
        if (ok) {
            link->SetPath(exe.c_str());
            link->SetWorkingDirectory(exe.parent_path().c_str());
            link->SetDescription(L"Play Dying Light with FaTrainer");
            link->SetIconLocation(exe.c_str(), 0);
            ok = SUCCEEDED(link->QueryInterface(IID_PPV_ARGS(&persist))) && SUCCEEDED(persist->Save(file.c_str(), TRUE));
        }
        if (persist) persist->Release();
        if (link) link->Release();
        if (!ok) return error = "could not write " + file.u8string(), false;
    }
    return true;
}
```
